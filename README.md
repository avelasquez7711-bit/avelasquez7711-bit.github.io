# Personal Portfolio Website | Angel Velasquez
My personal portfolio website built with HTML5 and CSS3. This as made to showcase projects, research, technical skills, and academic background in Computer Science journey.


## Key Features
- **Darkened Peacock Blue Theme:** Custom-styled dark slate and deep teal/peacock palette (`#008b8b` / `#070d12`) for readability and a modern look.
- **Responsive Layout:**
    - **Desktop:** Fixed left sidebar for profile info and photo paired with a scrollable content area.
    - **Mobile & Tablet:** Stacks seamlessly into a clean, mobile-friendly single-column layout.
- **Interactive Top Header:** Plain-text quick-navigation bar to jump directly to `#about`, `#projects`, `#experience`, `#skills`, and `#education`.
- **Project Showcase:** Horizontal project cards featuring live GIF previews, tech stack badges, and key metric bullet points.
- **Tech Stack Grid:** Interactive icon grid highlighting core programming languages, frameworks, and developer tools.
- **Streamlined Footer:** Minimalist footer displaying name and plain-text section navigation links.


## Built With

- **HTML5**
- **CSS3** 
- **FontAwesome:** Icons for social media links and contact details.
- **Devicon:** Tech and tool SVG/Font logos.
